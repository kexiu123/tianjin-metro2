# 天津特别版（非官方社区修改版）

本版本基于原项目源码制作，保留原作者版权与非商业许可。

## 手机游玩

推荐将整个文件夹部署到静态网页托管服务，或在支持本地网页文件的浏览器中打开 `index.html`。手机端建议横屏体验。

## 本版内容

- 新增「天津 · 2026」独立城市地图，选择地图后进入自由建造模式。
- 开局预置天津主要轨道交通线路及站点名称。
- 加入海河、主要道路走廊、中心城区片区和天津城市地标的示意底图。
- 可在原版自由建造系统中继续延伸线路、增加车站并规划未来线路。

## 重要准确性说明

这是首个可运行的天津版原型，不是官方天津地铁数据产品。轨道站点坐标、道路、行政片区与人口就业分布有游戏级近似；地理底图不是完整 OpenStreetMap 道路提取，部分线路按运营区段拆分。运营线路清单参考公开的 2026 年线网信息，仍建议后续逐站校准。未将尚未正式开通的线路当作既有运营线路。
